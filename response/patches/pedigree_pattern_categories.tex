Each inter-chromosomal patch in the scan was classified by its immediate flanking
background. A \emph{sandwich\_same\_hap} patch is one whose left and right
neighbouring segments both lie on the query chromosome and share a single
haplotype with each other and with the patch's own donor haplotype, so the patch
changes the chromosome of origin without changing the local haplotype background
(115 of the 494 within-community patches); a \emph{complex} patch is one whose
left or right neighbour is itself an inter-chromosomal segment, so it does not
sit in a clean same-chromosome sandwich (1 of the 494, after patches inside
acrocentric-like flanks are reclassified as such).
